# 🚀 Detailed Project Breakdowns

## 🔹 Project-1: Zomato Restaurant Review Analysis

An end-to-end Natural Language Processing (NLP) and predictive modeling pipeline to extract business intelligence from raw restaurant data.

### Features

- Merges restaurant metadata with customer review datasets.
- Cleans missing values and numerical inconsistencies.
- Performs sentiment analysis using VADER.
- Predicts restaurant ratings using a Random Forest Regressor.

**Key Technologies**

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VADER
- Scikit-Learn
